# Python — Syllabus

12 classes, 3 hours each. Sequenced to build toward backend work — data
structures and OOP first, since PostgreSQL and FastAPI both lean on them.

| # | Topic | What's covered | Folder |
|---|---|---|---|
| 1 | Python Basics | Variables, data types, type casting, operators, input/output, comments | [class-01-basics](./class-01-basics/) |
| 2 | Control Flow | if/elif/else, comparison & logical operators, nested conditionals | [class-02-control-flow](./class-02-control-flow/) |
| 3 | Loops | for, while, break/continue/pass, range(), loop patterns | [class-03-loops](./class-03-loops/) |
| 4 | Functions | def, parameters, default args, *args/**kwargs, return values, scope, lambda | [class-04-functions](./class-04-functions/) |
| 5 | Data Structures I | Lists and tuples: indexing, slicing, methods, mutability | [class-05-data-structures-1](./class-05-data-structures-1/) |
| 6 | Data Structures II | Dictionaries and sets: CRUD operations, comprehensions | [class-06-data-structures-2](./class-06-data-structures-2/) |
| 7 | Strings & Regex | String methods, f-strings, intro to regular expressions | [class-07-strings-regex](./class-07-strings-regex/) |
| 8 | File Handling & Exceptions | Reading/writing files, try/except/finally, custom exceptions | [class-08-files-exceptions](./class-08-files-exceptions/) |
| 9 | OOP I | Classes, objects, `__init__`, instance vs class attributes, methods | [class-09-oop-1](./class-09-oop-1/) |
| 10 | OOP II | Inheritance, polymorphism, encapsulation, magic/dunder methods | [class-10-oop-2](./class-10-oop-2/) |
| 11 | Modules, Packages & Environments | import system, pip, virtual environments, project structure | [class-11-modules-packages](./class-11-modules-packages/) |
| 12 | Advanced Python | Iterators, generators, decorators, intro to async/await | [class-12-advanced-python](./class-12-advanced-python/) |

Each class folder contains `notes.md`, `cheatsheet.md`, `examples.py`, and
`practice.py`. Quizzes for this module live in [`quizzes/`](./quizzes/).
