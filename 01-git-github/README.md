# 🔧 Git & GitHub

> **CodeForge: Python Backend Engineering Bootcamp — Git & GitHub Module**

This module introduces students to Git and GitHub as the foundation for professional software development and team collaboration.

The goal is not to memorize Git commands. Students should understand how developers use Git and GitHub to manage code, collaborate with teammates, track changes, and contribute to real software projects.

# 🎯 Learning Outcomes

By the end of this class, students should be able to:

- Understand version control and why it is necessary
- Understand Git vs GitHub
- Install and configure Git
- Create a Git repository
- Understand the Git working directory
- Track files using Git
- Create meaningful commits
- View Git history
- Create and manage branches
- Merge branches
- Resolve basic merge conflicts
- Create a GitHub repository
- Connect a local repository to GitHub
- Push code to GitHub
- Pull changes from GitHub
- Clone repositories
- Create and manage issues
- Create pull requests
- Understand basic team Git workflow
- Use GitHub as the central repository for future bootcamp projects
